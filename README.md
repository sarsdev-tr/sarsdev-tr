# Semih Arslan

I'm a computer engineering student at Adnan Menderes University in Aydın, Türkiye.

I write lightweight, fast software that runs locally on your own machine. If a tool can work offline, I build it offline so users keep their own data, send nothing to outside servers, and do not have to pay for services their own hardware can already handle.

## Projects

- [RadAir](https://github.com/sarsdev-tr/radair): an offline IEEE 802.11 airtime, spectrum, and packet analysis studio written in Rust.
- [Kelime Oyunu](https://github.com/sarsdev-tr/Kelime-Oyunu): a browser word game with offline PWA support and optional 1v1 live matches.
