Computer Engineering student at Adnan Menderes University. I combine core engineering logic with modern AI capabilities to build practical software, cross-platform apps, and system utilities.

---

### 💡 Engineering Philosophy & Vision

- **Offline-First & Data Privacy:** I strongly advocate for offline-first architecture and open-source software. In an era where user data privacy is constantly compromised, I believe local-first applications are essential to restoring data ownership.
- **AI as an Accelerator, Not a Replacement:** I don't rely on AI to write code blindly. I design the core architecture, define the application logic and system flow, and leverage AI to build, optimize, and iterate faster.
- **Problem-Driven Development:** I build software to fix real inefficiencies, optimize my personal workflows, and solve actual everyday problems.
